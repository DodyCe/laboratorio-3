# Nova Agencia · Cotizador de servicios

Cotizador web de servicios digitales con historial, calendario y gráficos.

Proyecto académico de desarrollo web.

## Funcionalidades

- Cálculo de cotizaciones por horas y tarifa, con descuento e IVA.
- Historial de cotizaciones y calendario de vigencia.
- Gráficos y exportación de reportes.

## Tecnologías

HTML5, CSS3 y JavaScript (ES6+).

## Ejecución local

Desde la carpeta del proyecto, inicia un servidor estático:

```sh
python -m http.server 8000
```

Abre [http://localhost:8000](http://localhost:8000) en tu navegador. También puedes usar Live Server de Visual Studio Code.
